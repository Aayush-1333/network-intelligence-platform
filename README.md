# Telecom Network Intelligence Platform

![nip](./assets/NIP_icon.png)

An enterprise-grade, multi-tenant solution designed to address complex operational challenges in the telecommunications domain by combining robust Google Cloud data pipelines with specialized AI agents.

## Overview

The platform provides trusted, low-latency network insights, automated alarm investigation, performance analysis, and change planning. It integrates native Google Cloud services with an intelligent agent layer to streamline telecommunications operations.

## Key Features

- Integrated Google Cloud Architecture: Leverages a robust suite of GCP services—including Cloud Run, BigQuery, Cloud SQL, Pub/Sub, and Memorystore—for scalable, event-driven, and high-volume data processing.

- Role-Based AI Agents: Utilizes specialized AI agents (powered by Gemini via Vertex AI) to autonomously investigate alarms, analyze performance metrics, and propose network changes.

- Python & Google ADK Foundation: Built using Python and the Google Agent Development Kit (ADK) as a shared codebase, ensuring consistent orchestration, typed tool usage, and rigorous evaluation frameworks.
